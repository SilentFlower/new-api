# 同渠道 Responses Compact 额度降级兼容

## Goal

当渠道周期预算触发同渠道换模型时，让 HTTP Responses Compact 保持原生协议和客户端字段，改用目标模型完成远程压缩；同时让所有 HTTP 额度降级请求的新增模型用量归属于实际目标模型，避免来源模型卡片在降级后继续增长。

## Background

- 线上请求 `a3ae01fcafdac4eb-LAX` 的 429 来自本服务的渠道周期额度拦截，不是上游模型限流。
- `controller/channel_limit_fallback.go:58` 当前直接排除 Responses Compact，因此来源模型超限后不会进入额度降级。
- `relay/responses_compact_passthrough.go:105` 当前重新取 `OriginModelName` 作为基础模型，会覆盖前置流程选择的降级目标。
- `service/channel_user_quota_usage.go:52` 当前使用 `OriginModelName` 记录模型预算用量。实际请求和账单已切换到目标模型时，来源模型卡片仍会按目标账单的正向额度继续增长。
- 用户已确认：额度降级成功后的新增模型用量应按实际目标模型累计；历史计数不自动重算。

## Requirements

### R1. Compact 同渠道降级

- Responses Compact 仅在额度动作解析到同一物理渠道时允许换模型，常规配置为 `channel_id=0`；解析到其他渠道时保持当前拒绝行为。
- 支持 V1 `/v1/responses/compact`、历史 body bridge 和 V2 HTTP 三种已有 Compact 入口。
- WebSocket Compact、任务接口和 Midjourney 等非现有 HTTP 文本降级入口保持不变。

### R2. 原生协议与模型语义

- 降级请求保持原始 Compact 模式、路径语义、未知字段、显式 `0` / `false` 和加密内容，只允许将顶层 `model` 改为配置的目标模型。
- Compact 降级继续绕过普通模型映射、参数覆盖、禁用字段处理和 DTO 重组。
- 未触发降级时，Compact 继续使用客户端基础模型，现有透传行为不变。
- `OriginModelName` 始终保留客户端原始模型；降级后的路由模型、出站模型、计费模型和消费日志主模型使用目标模型。

### R3. 单跳与副作用边界

- 来源预算超限后最多执行一次额度降级。
- 目标模型必须重新通过 Token 模型权限、分组能力、渠道状态、目标预算和 Compact 渠道能力校验。
- 目标不可用、无权限、超出目标预算、Compact 能力关闭或上游失败时，不得继续第三跳。
- 任何目标侧前置校验失败都不得调用上游或产生预扣、结算和消费日志。

### R4. 模型预算归属

- 所有现有 HTTP 额度降级请求结算成功后，渠道整体额度仍按实际目标渠道累计。
- 模型预算用量按额度降级的目标路由模型累计，而不是按客户端原始模型累计。
- 未发生额度降级时，模型预算归属保持现状。
- 模型映射仅是渠道内部上游别名，不能改变预算配置使用的路由模型身份。
- 已写入当前周期的历史用量不迁移、不拆分、不回退；修复生效后来源模型停止新增，目标模型从新请求开始累计。

### R5. 计费与审计

- 降级成功只预扣、结算和记录一次，并使用目标模型价格。
- 消费日志保留原始模型、目标模型、来源/目标渠道和触发预算信息。
- DeepSeek 等不支持原生 Compact 协议的模型不转换为本地摘要压缩。

## Acceptance Criteria

- [ ] AC1（R1、R2）：三种 HTTP Compact 模式在来源模型超限、同渠道目标可用时均返回成功，上游收到目标模型，除顶层 `model` 外的请求语义保持不变。
- [ ] AC2（R1）：Compact 配置为跨渠道目标时仍返回来源预算 429，目标渠道零调用。
- [ ] AC3（R2）：未超限 Compact 的请求体和响应保持现有原始透传，模型仍为客户端基础模型。
- [ ] AC4（R3）：目标预算耗尽、权限拒绝或 Compact 能力关闭时，零上游调用、零扣费、零消费日志且不发生第三跳。
- [ ] AC5（R5）：Compact 降级成功只生成一条按目标模型计费的消费日志，降级审计完整，用户和 Token 只扣一次。
- [ ] AC6（R4）：普通及 Compact 降级成功后，来源模型预算计数不增加，目标路由模型预算按本次正向结算额度增加。
- [ ] AC7（R4）：无降级请求及普通模型映射请求的预算归属保持原模型身份；渠道整体、个人日/周累计不受影响。
- [ ] AC8：现有普通 HTTP 降级、Compact 透传、WebSocket、任务和 Midjourney 边界回归通过。

## Out of Scope

- Compact 跨渠道降级。
- DeepSeek 等非原生 Compact 模型的本地摘要压缩。
- WebSocket Compact 的额度降级。
- 自动重算或迁移已经写入当前周期的历史模型额度。
- 数据库结构、管理端配置结构和前端展示调整。
