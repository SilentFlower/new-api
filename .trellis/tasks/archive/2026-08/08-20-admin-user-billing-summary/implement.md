# 管理员用户账务批量摘要接口实施计划

## 1. DTO、路由与 Controller

- [x] 新增请求、钱包摘要、订阅明细、订阅聚合、排序键、单用户结果和响应 DTO。
- [x] 单用户结果包含原生整数 `remote_status`、`remote_role`，不包含展示文案或同步动作。
- [x] 所有导出类型和公共方法添加中文 Javadoc，字段只包含本接口所需信息。
- [x] 在 `/api/user` 管理员路由组注册静态 `POST /billing-summary`，保持现有 `/:id` 路由兼容。
- [x] Controller 只负责 JSON 绑定、调用 Service 和统一响应。
- [x] 主体实现放入新增独立文件；现有 `router/api-router.go` 只增加一行注册。

## 2. Model 批量读取与周期投影

- [x] 新增最小用户账务行及批量读取函数，只选择 `id`、`quota`、`used_quota`、`group`、`status`、`role`。
- [x] 新增按用户 ID 和同一 `now` 批量读取有效订阅的函数，使用 GORM 通用条件和稳定顺序。
- [x] 新增按套餐 ID 批量读取套餐标题与重置字段的函数，空 ID 列表返回空结果。
- [x] 将懒重置算法提炼为共享周期投影，保持现有预消费写路径行为不变，摘要路径不保存。
- [x] 现有 `model/subscription.go` 只把写路径委托给新增投影文件，不夹带其他重构。
- [x] 增加批量读取、原生状态/角色、敏感字段排除和周期投影的 Model 测试。

## 3. Service 摘要与统一排序

- [x] 实现用户 ID 正整数校验、去重、500 上限和排序参数归一化。
- [x] 使用一次数据库时间编排用户、有效订阅和套餐的固定次数批量读取。
- [x] 将 Model 的 `status`、`role` 原样映射为 `remote_status`、`remote_role`，不做门户语义转换。
- [x] 生成 `ok`、`not_found`、`error`；无订阅明确返回零值和空列表。
- [x] 计算有限/无限订阅明细与聚合，对减法下限和 `int64` 加法溢出防护。
- [x] 生成统一 `sort_key`，实现未知置底、无限顺序、有限值升降序和用户 ID 倒序并列规则。
- [x] 增加表驱动测试，覆盖远端状态/角色、钱包、无订阅、有限、无限、混合、多订阅、懒重置、缺失套餐、溢出和排序组合。

## 4. Controller 与权限回归

- [x] 覆盖合法请求、非法 JSON、空列表、非法 ID、去重、超限、非法排序字段和数据库错误响应。
- [x] 通过路由或中间件集成测试验证管理员可访问，普通用户和未授权请求被拒绝。
- [x] 验证响应包含 `remote_status`、`remote_role`，但不包含 `password`、`access_token`、API Key、支付载荷或邮箱。
- [x] 验证摘要读取不会调用用户启停、提权或降权路径。

- [x] 运行 `go test ./...`。

- [x] 复核查询仅使用 GORM 通用语义，无数据库专用 SQL、迁移或逐用户查询。
- [x] 复核现有订阅预消费、重置、用户状态/角色管理和计费测试全部通过。

## 6. 风险与回滚点

- [x] 周期投影重构是最高风险点；先以现有测试锁定行为，再接入只读摘要。
- [x] `remote_role` 只能作为远端事实展示，任何后续同步必须继续走显式权限接口。
- [x] 排序契约是下游公开依赖；直接断言无限、未知、并列和跨批次可复现键值。
- [x] 若端点出现问题，可独立移除路由和新增文件；无数据库状态需要恢复。
